# Uptime Kuma — версия ub3dqy

**Версия в разработке:** до рабочего развёртывания нужна
[проверка исходных компонентов](SECURITY-BASELINE.md).

Своя версия на основе стабильного выпуска **2.5.8**. Uptime Kuma создана
Louis Lam и участниками исходного проекта. Лицензия MIT и сведения об авторах
сохранены. Эту версию развивает Dima Mak / ub3dqy.

## Первое дополнение: история проверок в CSV

Откройте нужную проверку, найдите блок **Выгрузка истории проверок**, выберите
период по UTC и нажмите **Скачать CSV**. Начало периода включается, конец — нет.
По умолчанию выбран предыдущий день до текущей минуты.

В файле: номер и название проверки, время по UTC, состояние, время ответа
в миллисекундах, сохранённая длительность в секундах и сообщение проверки.
Пароли, настройки, секретные ссылки и сохранённые ответы сервера не добавляются.
В самих сообщениях могут остаться личные сведения — проверьте файл перед передачей.
Для защиты от выполнения формул перед опасным текстом добавляется апостроф.
Если Excel не распознал файл, импортируйте его как UTF-8 с разделителем «запятая».

Нужен вход в учётную запись и доступ к выбранной проверке. Для одной учётной
записи одновременно готовится одна выгрузка. Пределы: 31 день, 50 000 проверок
и 8 МиБ. При превышении предлагается меньший период; неполный файл не создаётся.

Выгружаются только проверки, сохранившиеся в базе. Отсутствие строк не доказывает
работу или недоступность сайта. Паузы, пропуски, удалённая история и остановка
самой программы не превращаются в успешные проверки. Это исходная история,
а не готовый расчёт доступности или длительности аварий.

## Установка

Нужны поддерживаемая версия Node.js, соответствующая требованиям
`package.json`, и Git:

```sh
git clone --branch main https://github.com/ub3dqy/uptime-kuma.git
cd uptime-kuma
npm run setup
node server/server.js --host=127.0.0.1 --port=3001
```

Откройте `http://127.0.0.1:3001`, выберите базу данных и создайте администратора.
Этот пример доступен только с самого компьютера. Для общей установки настройте
защищённое соединение, доступ и постоянный запуск под выбранный сервер.
Перед обновлением сохраните копию данных и проверьте обновление на ней.

Команда `setup` собирает именно нашу версию. Готовая сборка исходного проекта
наших дополнений не содержит.

## Что проверено

31 октября 2026 года прошли девять проверок выгрузки, проверка переводов и
четыре сценария в Chrome: скачивание настоящего CSV, пустой период, узкий
экран и русский интерфейс. Проверка кода и сборка завершились без ошибок;
предупреждения исходного проекта остались.

Проверка выполнена с SQLite в Windows. MariaDB, установка через Docker,
полный набор проверок исходного проекта и работа на постоянном сервере
для этой версии ещё не подтверждены. Замечания к исходным компонентам
перечислены в [плане проверки перед запуском](SECURITY-BASELINE.md).

Дальше планируются сводки за период с учётом пропусков, группы клиентов и
печатные отчёты. В первой выгрузке этих возможностей ещё нет.
