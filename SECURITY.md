# Reporting a security issue

Use the [private security form](https://github.com/ub3dqy/uptime-kuma/security/advisories/new) for this edition of Uptime Kuma. Include the version, the affected feature, and steps to reproduce the issue. Remove credentials and other sensitive data from any examples.

## Как сообщить об уязвимости

Используйте [закрытую форму](https://github.com/ub3dqy/uptime-kuma/security/advisories/new) для этой версии Uptime Kuma. Укажите версию, затронутую возможность и шаги для повторения. Уберите пароли и другие личные данные из примеров.
