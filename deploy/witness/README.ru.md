# Независимый наблюдатель

Отдельная служба на сервере владельца обнаруживает полный отказ основной
установки. Она не открывает входящий порт, не подключается к рабочим сайтам
по SSH и не получает ключей ИИ. Проверка раз в 30 секунд обращается только
к заранее заданной установке по HTTPS. Запрос и ответ связаны случайным
номером, временем и подписью. Старая подпись повторно не принимается;
обычная страница с ответом 200 не подтверждает готовность базы.

После трёх неудач создаётся одно событие. Два последовательных успешных
ответа создают событие возврата связи. Состояние сохраняется до отправки
сообщения. При неопределённом результате отправка автоматически не повторяется:
сначала нужно проверить почту или Telegram. Принятие сообщения провайдером
не означает, что получатель его прочитал. Паузы между запусками службы сами
по себе не являются измеренной доступностью. История событий сохраняется
отдельными файлами без автоматического удаления.

Основная установка показывает время последнего подписанного запроса и наличие
каналов. При отсутствии каналов наблюдение работает, но внешние сообщения
не отправляются. Для уведомлений при полном отказе данные выбранных почты
и Telegram хранятся также на втором сервере. Нужны отдельное разрешение
владельца на выбранные каналы и фактическая проверка доставки.

Конфигурация передаётся через `LoadCredentialEncrypted` и шифруется
`systemd-creds encrypt --name=witness-config --with-key=host`. Команды
поддерживаются установленной системой 255. Файл доступен службе только
для чтения; служба работает от отдельного временного пользователя.
Она ограничена 5% процессора, 96 МБ памяти и 16 процессами. Пароли, токены,
адреса получателей и содержимое ошибок транспорта в журнал не записываются.
Указанная защита не скрывает секреты от владельца с полными правами на узле.

Временный файл разрешения systemd на этом узле имеет видимые права `0440`
из-за отдельного разрешения службы. Он принимается только в принадлежащем
root закрытом подкаталоге `/run/credentials` на файловой системе без права записи.
Обычные файлы настроек и состояния с доступом группы по-прежнему отклоняются.

Порядок установки: проверить исходный код и тесты; создать только собственный
каталог `/srv/uptime-kuma-witness`; передать конфигурацию через закрытый SSH
в стандартный ввод `systemd-creds`; проверить службу командой
`systemd-analyze verify`; запустить только `uptime-kuma-witness.service`.
Проверить два последовательных ответа, подпись и фактический журнал службы.
Нельзя останавливать основную рабочую установку ради имитации полного отказа:
такую проверку проводят на отдельной копии с отдельными тестовыми каналами.

Секрет основной установки находится в закрытом файле, путь к которому задаёт
`UPTIME_KUMA_WITNESS_CONFIG`; по умолчанию используется `data/witness/config.json`.
Этот стандартный путь входит в полную резервную копию данных.
Его нельзя включать в образ, исходники или общедоступные отчёты. Данные и
копии не удаляются при смене версии. Секреты второго узла нужно отдельно
сохранить владельцу: шифрование systemd привязано к этому серверу.

Формат конфигурации и проверки описаны в `witness.py`. В production разрешены
только проверенный HTTPS, почта с проверенным TLS и официальный адрес Telegram.
Отключения проверки сертификата и переходов на другой адрес нет.

Основание для передачи секретов службе: [документация systemd.exec](https://www.freedesktop.org/software/systemd/man/latest/systemd.exec.html#Credentials)
и [systemd-creds](https://www.freedesktop.org/software/systemd/man/latest/systemd-creds.html).

## Проверка сайтов со второго сервера

В HTTP-мониторе включите «Проверять со второго сервера». В закрытые настройки
наблюдателя добавьте список `sites` с номером монитора и его точным адресом.

    "sites": [{"id": 1, "url": "https://example.com/"}]

Можно выбрать до восьми сайтов. Указывайте конечные адреса общедоступных
страниц. Наблюдатель отправляет отдельный запрос GET и проверяет сертификат
для HTTPS. Карточка монитора показывает оба результата, время замера и ответ
второго сервера. Результат старше шести минут помечается как устаревший.
