# Первый запуск Uptime Kuma от ub3dqy

Программа следит за вашими сайтами, хранит историю и отправляет оповещения. Личный ИИ можно подключить позже.

## На Windows

1. Установите и запустите Docker Desktop по [официальной инструкции](https://docs.docker.com/desktop/setup/install/windows-install/).
2. Скачайте **Source code (zip)** на [странице выпуска](https://github.com/ub3dqy/uptime-kuma/releases/tag/v2.5.8-ub3dqy.preview.3) и распакуйте архив. Откройте **Start-Kuma.cmd**. При первом запуске программа соберётся из файлов этого выпуска и откроет панель в браузере.
3. Придумайте имя владельца и пароль от 15 символов. Помощник подставит одноразовый код установки. После первого входа откроются **Первые шаги**.

В следующий раз используйте тот же файл запуска. Контейнер называется **kuma-ub3dqy**, данные находятся в томе **kuma-ub3dqy_kuma_data**. Для их хранения хватает встроенной базы.

## На Linux и macOS

Понадобится запущенный Docker Engine 28 или новее с Compose. Откройте папку этого выпуска и выполните одну команду.

```bash
bash start-kuma.sh
```

Откройте напечатанную ссылку на том же компьютере. До создания владельца в ссылке есть одноразовый код. Держите её у себя. Панель по умолчанию доступна на `127.0.0.1:3001`. Сокращённая ссылка после входа — `http://127.0.0.1:3001/dashboard`.

Если вы ставите программу на отдельный сервер, подключитесь к его панели через защищённый доступ и создайте владельца до публикации адреса. Для постоянного доступа с телефона используйте HTTPS и [руководство по серверной установке нашей версии](../FORK.ru.md#резервная-копия-и-доступ-с-сервера).

## Внутри программы

1. **Сайт.** Введите адрес, например `example.com`, и нажмите **Начать проверку**. Программа проверит его по HTTPS раз в минуту. Карточка покажет настоящий результат. Для DNS, сервера или сценария в браузере используйте **Выбрать другой тип проверки**.
2. **Оповещения.** Выберите Telegram или почту, сохраните канал и отправьте тест. Когда сообщение появится у вас, отметьте получение и выберите проверки, по которым хотите получать сообщения. Подключение управления из чата описано в [инструкции для Telegram](TELEGRAM-CONTROL.ru.md).
3. **Личный ИИ.** Выберите подключение и выполните тест, если хотите получать объяснения сбоев. К настройке можно вернуться через **Настройки → Первые шаги** или **Проекты → Личный ИИ**.
4. **Защита аккаунта.** На последнем шаге откройте настройки защиты и подключите второй шаг входа. Храните пароль отдельно от приложения подтверждения.

В **Обзоре** видны последние наблюдения. В карточке сайта можно смотреть историю, выгружать её и поставить проверку на паузу. **Обслуживание** задаёт время работ, а **Страницы статуса** публикуют выбранные проверки для посетителей.

## Как подключить свой ИИ

| Что есть у вас | Что выбрать в Uptime Kuma |
| --- | --- |
| Ключ OpenAI | **OpenAI по ключу**. Создайте ключ в [OpenAI](https://platform.openai.com/api-keys), вставьте его и сохраните. |
| Доступ к входу через ChatGPT | **Подписка ChatGPT**. Сохраните выбор и используйте **Continue with ChatGPT**. Официальное окно попросит подтвердить доступ. |
| Ключ Anthropic | **Claude от Anthropic по ключу**. Создайте ключ в [Claude Console](https://platform.claude.com/settings/keys), вставьте его и сохраните. |

После подключения нажмите **Загрузить доступные модели**, выберите модель, сохраните и отправьте тест. Только успешный ответ превращает сохранённое подключение в проверенное. Тест использует короткий пример без сведений о ваших сайтах. Передача истории, названий и адресов настраивается отдельно в **Лимиты и передача данных**.

На локальной установке вход ChatGPT возвращается в эту же панель. Для установки по удалённому адресу используйте шаги с [помощником входа](PROJECTS-AND-AI.ru.md#собственная-подписка-chatgpt). Доступ зависит от возможностей вашего аккаунта. Если у вас есть кредиты для API в составе тарифа, активируйте их у провайдера и выберите подключение по ключу. [Кредиты OpenAI](https://developers.openai.com/api/docs/guides/chatgpt-api-credits) · [Кредиты Claude](https://support.claude.com/en/articles/8977456-how-do-i-pay-for-my-claude-api-usage)

## Копия и обновление

Держите копию всего тома данных и предыдущую сборку перед обновлением. В Docker Desktop откройте **Volumes**, выберите **kuma-ub3dqy_kuma_data** и сделайте локальный экспорт. Сохраните файл в закрытом месте. Убедитесь, что из него можно запустить отдельную копию с историей. [Экспорт и проверка тома](https://docs.docker.com/desktop/use-desktop/volumes/)

Для рабочей установки на сервере используйте [проверку восстановления и порядок отката](../FORK.ru.md#резервная-копия-и-доступ-с-сервера). Обновление выполняется из нового выпуска ub3dqy. После запуска проверьте, что в панели видны прежние сайты и новые наблюдения, затем отправьте тестовое уведомление.

## Перенос существующей установки

Файлы быстрого запуска предназначены для отдельной установки. Если в папке уже лежит база, помощник направит к инструкции переноса. Сначала сделайте копию всего каталога данных и сохраните старую сборку. Переносите её с оператором по [инструкции для сервера](../FORK.ru.md#резервная-копия-и-доступ-с-сервера), используя отдельный проверочный запуск. Для прежней установки с MariaDB сохраните её параметры и резервную копию базы.

## Если запуск остановился

- **Docker закрыт.** Откройте Docker Desktop, дождитесь готовности и повторите запуск.
- **Порт 3001 занят.** Проверьте, открыта ли ваша панель по `http://127.0.0.1:3001`. На Linux или macOS можно выбрать другой порт командой `KUMA_PORT=3002 bash start-kuma.sh`.
- **Код установки не подходит.** Снова откройте файл запуска. При ручном запуске возьмите код из файла `.setup-code` в закрытой папке данных.
- **Сайт не проверяется.** Откройте карточку и прочитайте причину. Проверьте адрес и работает ли сайт с компьютера, на котором запущена программа.
